Do more modalities mean better predictions?

Do movie posters and text add useful signal beyond structured metadata?

Exploratory course project

Machine learningPythonPCAMultimodal modeling
Read project and notebook

The approach

Aligned 568 titles from 615 collected IMDb ratings. Compared 36 metadata features with ResNet-50 poster embeddings and TF-IDF/SVD text representations using dimensionality reduction, classification and modality ablations.

What the analysis shows

The exploratory run suggested that adding high-dimensional poster and text features did not automatically improve on metadata. The public notebook replaces the primary comparison with fold-local preprocessing pipelines.

How to read the results

The original evaluation fitted preprocessing before the train/test split. A leakage-free rerun is still needed; historical performance estimates are not presented as validated generalization results.
