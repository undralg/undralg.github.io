Discrete and multi-level models

Introduction

In this report, we compare groups of students who completed a standardized test. They are grouped by the year in which they took the test. The challenge here is that the data from the different years are provided in an inconsistent format. Each group provides a histogram of results but the bins of the histograms aren’t spaced in the same way from year to year.

Motivating question: Did some years get better scores overall than other years? Or are the scores consistent across all years?

Figure 1: Some groups have an even bin spacing. All bins have the same width along the score axis. Each test score is an integer between 0 (nothing correct) and 1500 (everything correct) but test scores are typically between 800 and 1500.

Figure 2: Some groups have an uneven bin spacing. Wider bins are used in score ranges where fewer students ended up and narrower bins are used in score ranges where the most students ended up, to show more detail.

Let’s start by assuming a simple Normal score distribution, although it is not ideal for a few reasons. The test scores are bounded (0 to 1500) and often exhibit skewness or ceiling effects. A Normal distribution has unbounded support and is symmetric, so it might not capture these characteristics well. A Normal distribution’s tails extend infinitely in both directions and thin out, so it may not accurately estimate the proportion of extremely high or low scores.

We will consider 2 models under the Normal assumption.

1. No Pooling Model for Test Scores

In this model, we assume that the test scores for each year are generated independently from a Normal distribution.

Priors

We place the following priors on the parameters of the Normal distribution:

  • For the mean score μ\mu, we assume:

μ∼𝒩(1000,3002) \mu \sim \mathcal{N}(1000, 300^2)

This prior reflects our belief that, on average, test scores are around 1000 with a standard deviation of 300.

  • For the standard deviation σ\sigma, we assume:

σ∼HalfNormal(300) \sigma \sim \text{HalfNormal}(300)

Since standard deviations must be positive, we use a HalfNormal prior with a scale of 300. This is a weakly informative prior, acknowledging that the spread of scores is likely around 300, but with considerable uncertainty.

Likelihood

The data for each year are provided in the form of binned counts, with bin edges defined (for example, 0,125,250,…,15000, 125, 250, \dots, 1500). Since we do not have the individual test scores but rather the number of students falling into each bin, we compute the probability mass for each bin based on the assumed Normal distribution.

We compute the cumulative probability at each bin edge using the CDF of the Normal distribution. Let F(x)F(x) denote the CDF of 𝒩(μ,σ)\mathcal{N}(\mu, \sigma), then the probability mass for the ii-th bin is given by:

pi=F(bi)−F(bi−1), p_i = F(b_i) - F(b_{i-1}),

where bi−1b_{i-1} and bib_i are consecutive bin edges. In our implementation, we compute these differences using the diff operation on the vector of cumulative probabilities.

Given the vector of bin probabilities 𝐩\mathbf{p}, the observed bin counts (say, 𝐲\mathbf{y}) are modeled as a draw from a Multinomial distribution:

𝐲∼Multinomial(N,𝐩), \mathbf{y} \sim \text{Multinomial}(N, \mathbf{p}),

where N=∑iyiN = \sum_i y_i is the total number of observations (students).

By computing the differences in the Normal CDF at the specified bin edges, we capture the probability mass corresponding to each bin. This approach is equivalent to assuming that the underlying scores follow a continuous distribution (here, Normal) and that the observed bin counts are generated by grouping these continuous scores into the defined intervals. The Multinomial likelihood is appropriate because the counts in the bins follow a multinomial process given the total number of observations.

        'bin_counts': np.array([1, 2, 11, 15, 27, 81, 195, 575, 1717, 3563, 2863, 847]),
    },

        'bin_counts': np.array([11, 16, 94, 142, 309, 808, 752, 1073, 1505, 1626, 2555, 932]),
    },
    {

        'bin_edges': np.array([0, 400, 600, 800, 900, 1000, 1100, 1150, 1200, 1250, 1300, 1400, 1500]),
        'bin_counts': np.array([15, 32, 130, 257, 505, 1227, 1051, 1381, 1558, 1355, 1837, 550]),
    },
]

# Dictionaries to store models and traces for each year
models_no_pool = {}
traces_no_pool = {}

# Loop over each year, build and sample the model
for d in data_per_year:
    year = d['year']
    bin_edges = d['bin_edges']
    bin_counts = d['bin_counts']
    total_counts = bin_counts.sum()
    
    with pm.Model() as model:
        # Priors: we assume a Normal for the mean and a HalfNormal for the standard deviation.
        mu = pm.Normal("mu", mu=1000, sigma=300)
        sigma = pm.HalfNormal("sigma", sigma=300)
        
        # Compute the cumulative probabilities at the bin edges.
        # Because bin_edges already include 0 and 1500, we simply evaluate the CDF at those points.
        cdfs = pm.math.exp(pm.logcdf(pm.Normal.dist(mu=mu, sigma=sigma), bin_edges))
        # Compute the probability mass in each bin via differences between successive CDF values.
        p_raw = pt.extra_ops.diff(cdfs)
        
        # Avoid exactly zero probabilities by clipping and renormalizing. In addition, this lets us condition
        # the likelihood on the bounded scores. 
        p = pt.clip(p_raw, eps, 1)
        p = p / pt.sum(p)
        
        # Likelihood: the observed bin counts are modeled as a draw from a Multinomial.
        counts = pm.Multinomial("counts", n=total_counts, p=p, observed=bin_counts)
        
        # Sample from the posterior.
        trace = pm.sample(1000, tune=1000, return_inferencedata=True)
        models_no_pool[year] = model
        traces_no_pool[year] = trace

Note: In this model we compute the CDF only at the specified bin edges (0 to 1500) and then renormalize the differences so that they sum to 1. This effectively conditions the likelihood on scores being within those bounds. Even though the underlying Normal distribution has unbounded support, by focusing only on the interval [0,1500] and renormalizing, the model “ignores” the probability mass outside this range. This approach lets the model work with bounded data without being confused by the Normal’s theoretical tails.

Hierarchical Model for Test Scores

In this model, we assume that the test scores for each year are generated from a Normal distribution with year‐specific parameters. Rather than estimating each year’s parameters independently (no pooling), we assume that these parameters come from common (population-level) distributions. This hierarchical approach allows us to “borrow strength” across years.

Priors

For each year jj, we assume that the test scores are distributed as

Xj∼𝒩(μj,σj2). X_j \sim \mathcal{N}(\mu_j, \sigma_j^2).

Year-specific Means (μj\mu_j):

We assume that the individual year means come from a common population distribution:

μj∼𝒩(μpop,σμ2). \mu_j \sim \mathcal{N}(\mu_{pop}, \sigma_{\mu}^2).

We set the following hyperpriors:

  • Population Mean:

    μpop∼𝒩(1000,2122) \mu_{pop} \sim \mathcal{N}(1000, 212^2)

  • Between-Year Variability in Means:

    σμ∼HalfNormal(212). \sigma_{\mu} \sim \text{HalfNormal}(212).

212 was chosen because, marginally, each year’s mean has variance

σpop2+σμ2≈2122+2122≈3002, \sigma_{\text{pop}}^2 + \sigma_{\mu}^2 \approx 212^2 + 212^2 \approx 300^2,

which is similar in flexibility to the no pooling model where

μj∼𝒩(1000,3002). \mu_j \sim \mathcal{N}(1000, 300^2).

Year-specific Standard Deviations (σj\sigma_j):

We assume that the standard deviations for each year come from a common distribution:

σj∼HalfNormal(σσ) \sigma_j \sim \text{HalfNormal}(\sigma_{\sigma})

with hyperprior

σσ∼HalfNormal(300). \sigma_{\sigma} \sim \text{HalfNormal}(300).

This choice ensures that the standard deviations remain positive and reflects our uncertainty about the variability in scores across years.

Likelihood

The data for each year are provided as binned counts. Suppose the bin edges are given by

b0,b1,…,bK, b_0, b_1, \dots, b_K,

(for example, 0,125,250,…,15000, 125, 250, \dots, 1500), and the observed counts in these bins are

y1,y2,…,yK, y_1, y_2, \dots, y_K,

with a total number of observations

N=∑i=1Kyi. N = \sum_{i=1}^{K} y_i.

For a given year jj, the cumulative distribution function (CDF) of 𝒩(μj,σj)\mathcal{N}(\mu_j, \sigma_j) is

F(x;μj,σj)=P(Xj≤x). F(x; \mu_j, \sigma_j) = P(X_j \le x).

The probability mass in the ii-th bin is then

pi=F(bi;μj,σj)−F(bi−1;μj,σj). p_i = F(b_i; \mu_j, \sigma_j) - F(b_{i-1}; \mu_j, \sigma_j).

Since the Normal distribution has unbounded support, there is some probability mass outside the range [0,1500][0, 1500]. However, in our implementation we only evaluate the CDF at the bin edges (which include 0 and 1500) and then renormalize the vector

𝐩=(p1,p2,…,pK) \mathbf{p} = (p_1, p_2, \dots, p_K)

so that

∑i=1Kpi=1. \sum_{i=1}^K p_i = 1.

This effectively conditions the model on scores lying within the observed range.

Finally, given the total number of test takers NN, the observed binned counts are modeled as a draw from a Multinomial distribution:

𝐲∼Multinomial(N,𝐩). \mathbf{y} \sim \text{Multinomial}(N, \mathbf{p}).

By placing hyperpriors on μj\mu_j and σj\sigma_j, we allow the information from all years to inform each individual year’s estimates. This partial pooling helps stabilize estimates, especially in years with less data. However, in this case, the number of test takers across years is relatively stable.

import pymc as pm
import pytensor.tensor as pt
import numpy as np

# A small constant to avoid zero probabilities in the tail
eps = 1e-9

# Number of years (each year in data_per_year gets its own parameters)
n_years = len(data_per_year)

with pm.Model() as hierarchical_model:
    # Hyperpriors for the population-level means (μ)
    mu_pop = pm.Normal("mu_pop", mu=1000, sigma=212)
    sigma_mu = pm.HalfNormal("sigma_mu", sigma=212)
    
    # Hyperprior for the variability in standard deviations across years
    # This reflects our uncertainty about how much each year’s standard deviation can vary.
    sigma_sigma = pm.HalfNormal("sigma_sigma", sigma=300)
    
    # Year-specific parameters (partial pooling)
    mu_year = pm.Normal("mu_year", mu=mu_pop, sigma=sigma_mu, shape=n_years)
    sigma_year = pm.HalfNormal("sigma_year", sigma=sigma_sigma, shape=n_years)
    
    # Likelihood for each year
    for i, d in enumerate(data_per_year):
        bin_edges = d['bin_edges']
        bin_counts = d['bin_counts']
        total_counts = bin_counts.sum()
        
        # Compute the cumulative probability at each bin edge using the year-specific parameters.
        cdfs = pm.math.exp(pm.logcdf(pm.Normal.dist(mu=mu_year[i], sigma=sigma_year[i]), bin_edges))
        # The probability mass in each bin is the difference between successive CDF values.
        p_raw = pt.extra_ops.diff(cdfs)
        
        # Avoid exactly zero probabilities by clipping and renormalizing.
        p = pt.clip(p_raw, eps, 1)
        p = p / pt.sum(p)
        
        # Likelihood: the observed bin counts for the year are modeled as a Multinomial draw.
        pm.Multinomial(f"counts_year_{d['year']}", n=total_counts, p=p, observed=bin_counts)
    
    # Sample from the posterior.
    trace_hier = pm.sample(1000, tune=2000, target_accept=0.999, max_treedepth=15, return_inferencedata=True)

Improved Hierarchical Model for Test Scores Using a Logit‑Normal Distribution

In this model we assume that the underlying (scaled) test scores follow a Logit‑Normal distribution. Because test scores are bounded between 0 and 1500 and may exhibit skewness or ceiling effects—features that a standard Normal does not capture—we work on the logit scale and then transform back to the original score scale.

For each year jj, we assume that the (scaled) score XjX_j (with Xj∈(0,1)X_j \in (0,1)) is modeled on the logit scale as

logit⁡(Xj)∼𝒩(μj,σj2). \operatorname{logit}(X_j) \sim \mathcal{N}(\mu_j,\,\sigma_j^2).

The effective mean on the original score scale is defined as

μeffective,j=sigmoid⁡(μj)×1500. \mu_{\text{effective},j} = \operatorname{sigmoid}(\mu_j) \times 1500.

Priors

Year-specific Parameters:

  • Means:

    For each year jj, the logit-scale mean is modeled hierarchically as

    μj∼𝒩(μpop,σμ2). \mu_j \sim \mathcal{N}(\mu_{pop},\,\sigma_{\mu}^2).

    We set the hyperpriors for the population-level means as

    μpop∼𝒩(0.693,0.642) \mu_{pop} \sim \mathcal{N}(0.693,\,0.64^2)

    and

    σμ∼HalfNormal(0.64). \sigma_{\mu} \sim \text{HalfNormal}(0.64).

    The value 0.6930.693 is chosen because

    sigmoid⁡(0.693)≈0.667, \operatorname{sigmoid}(0.693) \approx 0.667,

    and when we multiply by 1500, the effective mean becomes

    0.667×1500≈1000. 0.667 \times 1500 \approx 1000.

    In other words, these priors are set on the logit scale so that, after applying the sigmoid transformation and scaling by 1500, the effective means are centered near 1000. A logit-scale standard deviation of 0.640.64 for both μpop\mu_{pop} and the between-year variability (via σμ\sigma_{\mu}) implies that typical deviations on the logit scale translate to an effective standard deviation on the score scale of roughly

    0.64×sigmoid⁡(0.693)(1−sigmoid⁡(0.693))×1500≈0.64×0.222×1500≈213. 0.64 \times \operatorname{sigmoid}(0.693)\,(1-\operatorname{sigmoid}(0.693)) \times 1500 \approx 0.64 \times 0.222 \times 1500 \approx 213.

    This provides moderate variability in the effective means across years.

  • Standard Deviations:

    For each year jj, we assume that the standard deviation (on the logit scale) is modeled as

    σj∼HalfNormal(σσ), \sigma_j \sim \text{HalfNormal}(\sigma_{\sigma}),

    with the hyperprior

    σσ∼HalfNormal(0.9). \sigma_{\sigma} \sim \text{HalfNormal}(0.9).

    Although 0.90.9 might seem modest on the logit scale, the nonlinearity of the sigmoid function means that small differences on the logit scale can lead to substantial differences on the original score scale. This setup is intended to yield effective variability in the standard deviations that is comparable to the no pooling model (where the standard deviation was modeled as HalfNormal(300)\text{HalfNormal}(300) on the score scale).

Likelihood

The data for each year are provided as binned counts. Suppose for a given year the bin edges are

b0,b1,…,bK, b_0,\,b_1,\,\dots,\,b_K,

(e.g., 0,125,250,…,15000,\,125,\,250,\,\dots,\,1500) and the observed counts are

y1,y2,…,yK, y_1,\,y_2,\,\dots,\,y_K,

with total observations

N=∑i=1Kyi. N = \sum_{i=1}^{K} y_i.

We first scale the bin edges to the unit interval by computing

bi*=bi1500. b_i^* = \frac{b_i}{1500}.

Next, we compute the cumulative probability at each scaled bin edge using a differentiable Logit‑Normal CDF defined as

$$ \text{logit\_normal\_cdf}(x,\mu,\sigma) = 0.5\Bigl[1 + \operatorname{erf}\Bigl(\frac{\ln\frac{x}{1-x} - \mu}{\sigma\sqrt{2}}\Bigr)\Bigr]. $$

For a given year jj, the probability mass in the ii-th bin is

pi=F(bi*;μj,σj)−F(bi−1*;μj,σj), p_i = F(b_i^*;\mu_j,\sigma_j) - F(b_{i-1}^*;\mu_j,\sigma_j),

where F(x;μj,σj)F(x;\mu_j,\sigma_j) is the Logit‑Normal CDF. Since there might be probability mass outside the observed range, we then renormalize the vector

𝐩=(p1,p2,…,pK) \mathbf{p} = (p_1, p_2, \dots, p_K)

so that

∑i=1Kpi=1. \sum_{i=1}^{K} p_i = 1.

Finally, the observed bin counts are modeled as

𝐲∼Multinomial(N,𝐩). \mathbf{y} \sim \text{Multinomial}(N, \mathbf{p}).

import pymc as pm
import pytensor.tensor as pt
import numpy as np

# A small constant to avoid zero probabilities in the tail
eps = 1e-9

# Number of years (each year in data_per_year gets its own parameters)
n_years = len(data_per_year)
scale = 1500  # maximum possible score

with pm.Model() as logit_normal_hier_model:
    # Hyperpriors for the population-level means (on the logit scale)
    mu_pop = pm.Normal("mu_pop", mu=0.693, sigma=0.64)
    sigma_mu = pm.HalfNormal("sigma_mu", sigma=0.64)
    
    # Hyperpriors for the standard deviations (on the logit scale)
    sigma_sigma = pm.HalfNormal("sigma_sigma", sigma=0.9)
    
    # Year-specific parameters (partial pooling) on the logit scale:
    mu_year = pm.Normal("mu_year", mu=mu_pop, sigma=sigma_mu, shape=n_years)
    sigma_year = pm.HalfNormal("sigma_year", sigma=sigma_sigma, shape=n_years)
    
    # For reporting, define an effective mean on the score scale.
    mu_effective = pm.Deterministic("mu_effective", pm.math.sigmoid(mu_year) * scale)
    
    # Likelihood: For each year, compute the probability mass in each bin.
    # The differentiable logit-normal CDF:
    def logit_normal_cdf(x, mu, sigma, eps=1e-6):
        x_clipped = pm.math.clip(x, eps, 1-eps)
        logit_x = pm.math.log(x_clipped/(1-x_clipped))
        return 0.5 * (1 + pm.math.erf((logit_x - mu) / (sigma * pt.sqrt(2))))
    
    for i, d in enumerate(data_per_year):
        bin_edges = d['bin_edges']
        bin_counts = d['bin_counts']
        total_counts = bin_counts.sum()
        
        # Scale bin edges to [0,1]
        bin_edges_scaled = bin_edges / scale
        
        # Compute the logit-normal CDF at each bin edge using the year-specific parameters.
        cdfs = logit_normal_cdf(bin_edges_scaled, mu_year[i], sigma_year[i])
        p_raw = pt.extra_ops.diff(cdfs)
        p = pt.clip(p_raw, eps, 1)
        p = p / pt.sum(p)
        
        # Likelihood: observed counts are modeled as a draw from a Multinomial.
        pm.Multinomial(f"counts_year_{d['year']}", n=total_counts, p=p, observed=bin_counts)
    
    trace_lognormal_hier = pm.sample(1000, tune=1500, target_accept=0.999, return_inferencedata=True)

import numpy as np

# Create a figure with a 2x2 grid of subplots
fig, axes = plt.subplots(2, 2, figsize=(16, 12))

# Define the order of years in the grid
years_order = [2021, 2022, 2023, 2024]

# To ensure consistent y-axis limits, determine the maximum y-value across all years
max_y = 0
for year in years_order:
    # Find the data for this year
    year_data = next(d for d in data_per_year if d['year'] == year)
    bin_counts = year_data['bin_counts']
    # Get hierarchical posterior predictive for this year:
    with logit_normal_hier_model:
        ppc_hier = pm.sample_posterior_predictive(
            trace_lognormal_hier, 
            var_names=[f"counts_year_{year}"],
            return_inferencedata=True
        )
    ppc_counts = ppc_hier.posterior_predictive[f"counts_year_{year}"].mean(dim=["chain", "draw"]).values
    max_y = max(max_y, np.max(bin_counts), np.max(ppc_counts))
max_y = max_y * 1.1  # add some padding

# Define consistent tick positions for all plots
common_ticks = np.array([0, 400, 800, 1000, 1200, 1400, 1500])

# Plot each year in the grid
for i, year in enumerate(years_order):
    # Retrieve data for this year
    year_data = next(d for d in data_per_year if d['year'] == year)
    bin_edges = year_data['bin_edges']
    observed_counts = year_data['bin_counts']
    
    # For the hierarchical logit-normal model, extract the year-specific parameter estimates.
    # The trace uses dimensions named "mu_year_dim_0" and "sigma_year_dim_0".
    mu_mean = trace_lognormal_hier.posterior["mu_year"].isel(mu_year_dim_0=i).mean().values
    sigma_mean = trace_lognormal_hier.posterior["sigma_year"].isel(sigma_year_dim_0=i).mean().values
    
    # Get hierarchical posterior predictive for counts_year_{year}
    with logit_normal_hier_model:
        ppc_hier = pm.sample_posterior_predictive(
            trace_lognormal_hier, 
            var_names=[f"counts_year_{year}"],
            return_inferencedata=True
        )
    ppc_counts = ppc_hier.posterior_predictive[f"counts_year_{year}"].mean(dim=["chain", "draw"]).values
    
    # Calculate x positions and bar widths based on bin edges
    x_left = bin_edges[:-1]
    bin_widths = np.diff(bin_edges)
    
    # Determine subplot position (row, col)
    row = i // 2
    col = i % 2
    ax = axes[row, col]
    
    # Plot observed counts as bars (bars span the bin from left edge to next edge)
    obs_bars = ax.bar(
        x_left, 
        observed_counts, 
        width=bin_widths, 
        align='edge', 
        alpha=0.65, 
        color='#3498db',
        edgecolor='#2980b9',
        linewidth=1,
        label='Observed'
    )
    
    # Plot posterior predictive counts as bars using the same positions
    pred_bars = ax.bar(
        x_left, 
        ppc_counts, 
        width=bin_widths, 
        align='edge', 
        alpha=0.65, 
        color='#e74c3c',
        edgecolor='#c0392b',
        linewidth=1,
        label='Posterior Predictive'
    )
    
    # Set consistent axis limits and ticks
    ax.set_xlim(0, 1500)
    ax.set_ylim(0, max_y)
    ax.set_xticks(common_ticks)
    ax.set_xticklabels([str(tick) for tick in common_ticks], fontsize=10)
    
    # Add title and axis labels
    ax.set_title(f"Year {year}: Hierarchical Logit-Normal Distribution Model", fontsize=14, fontweight='bold')
    if row == 1:
        ax.set_xlabel("Score", fontsize=12, fontweight='bold')
    if col == 0:
        ax.set_ylabel("Number of Students", fontsize=12, fontweight='bold')
    
    # Add model parameter means to the plot as a text box
    textstr = f'μ = {mu_mean:.1f}\nσ = {sigma_mean:.1f}'
    props = dict(boxstyle='round', facecolor='white', alpha=0.7)
    ax.text(0.05, 0.95, textstr, transform=ax.transAxes, fontsize=12,
            verticalalignment='top', bbox=props)
    
# Create a common legend for the entire figure
legend_elements = [
    plt.Rectangle((0,0), 1, 1, fc='#3498db', ec='#2980b9', alpha=0.65),
    plt.Rectangle((0,0), 1, 1, fc='#e74c3c', ec='#c0392b', alpha=0.65)
]
fig.legend(
    legend_elements, 
    ['Observed', 'Posterior Predictive'],
    loc='upper center', ncol=2, fontsize=12, bbox_to_anchor=(0.5, 0.98)
)

# Overall figure title
fig.suptitle("Observed vs. Posterior Predictive by Year (Hierarchical Logit-Normal Model)", fontsize=16, fontweight='bold', y=1.05)

plt.tight_layout()
plt.subplots_adjust(top=0.9)  # leave room for the suptitle
plt.show()

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

scale = 1500  # scaling factor for the logit-normal model

# Create lists to hold summary statistics for μ from each model.
np_summary   = []  # for no pooling estimates
hier_summary = []  # for hierarchical (normal) estimates
ln_summary   = []  # for logit-normal estimates

# Loop over each year's data.
for idx, d in enumerate(data_per_year):
    year = d['year']
    
    # --- No Pooling Summary ---
    trace_np = traces_no_pool[year].posterior
    mu_np_samples = trace_np["mu"].values.flatten()
    lower_np   = np.percentile(mu_np_samples, 2.5)
    median_np  = np.median(mu_np_samples)
    upper_np   = np.percentile(mu_np_samples, 97.5)
    np_summary.append({
        "year": year,
        "model": "No Pooling",
        "median": median_np,
        "lower": lower_np,
        "upper": upper_np
    })
    
    # --- Hierarchical (Normal) Model Summary ---
    mu_hier_samples = trace_hier.posterior["mu_year"].isel(mu_year_dim_0=idx).values.flatten()
    lower_hier = np.percentile(mu_hier_samples, 2.5)
    median_hier = np.median(mu_hier_samples)
    upper_hier = np.percentile(mu_hier_samples, 97.5)
    hier_summary.append({
        "year": year,
        "model": "Hierarchical",
        "median": median_hier,
        "lower": lower_hier,
        "upper": upper_hier
    })
    
    # --- Logit Normal Model Summary ---
    # For the logit-normal model, use the effective μ (mu_effective) which is already scaled.
    # Use the correct dimension name, e.g., "mu_effective_dim_0"
    mu_ln_samples = trace_lognormal_hier.posterior["mu_effective"].isel(mu_effective_dim_0=idx).values.flatten()
    lower_ln = np.percentile(mu_ln_samples, 2.5)
    median_ln = np.median(mu_ln_samples)
    upper_ln = np.percentile(mu_ln_samples, 97.5)
    ln_summary.append({
        "year": year,
        "model": "Logit Normal",
        "median": median_ln,
        "lower": lower_ln,
        "upper": upper_ln
    })

# Combine the summaries into a single DataFrame.
summary_df = pd.DataFrame(np_summary + hier_summary + ln_summary)
# Convert the year to numeric for ordering.
summary_df["year"] = summary_df["year"].astype(int)
summary_df = summary_df.sort_values("year")

# Map each year to a numeric position (e.g., 2021 -> 1, 2022 -> 2, etc.).
unique_years = sorted(summary_df["year"].unique())
year_to_pos = {year: pos for pos, year in enumerate(unique_years, start=1)}

# Define vertical offsets so that the three models' points for each year don't overlap.
offsets = {"No Pooling": -0.2, "Hierarchical": 0.0, "Logit Normal": 0.2}

# Define colors for each model.
colors = {
    "No Pooling": "#e74c3c", 
    "Hierarchical": "#3498db",
    "Logit Normal": "#2ecc71"
}

plt.figure(figsize=(8, 6))

# Plot error bars for each model with vertical offsets.
for model in summary_df["model"].unique():
    df_model = summary_df[summary_df["model"] == model].copy()
    # Compute the y-position for each year plus an offset.
    df_model["ypos"] = df_model["year"].map(year_to_pos) + offsets[model]
    plt.errorbar(
        df_model["median"],
        df_model["ypos"],
        xerr=[df_model["median"] - df_model["lower"], df_model["upper"] - df_model["median"]],
        fmt='o', color=colors[model], capsize=5, label=model, markersize=8
    )

plt.xlabel("Estimated μ (Score Mean)", fontsize=12, fontweight='bold')
plt.ylabel("Year", fontsize=12, fontweight='bold')
plt.title("Comparison of μ Estimates:\nNo Pooling vs. Hierarchical vs. Logit Normal", fontsize=14, fontweight='bold')
# Set y-ticks at the base positions.
plt.yticks(list(year_to_pos.values()), [str(year) for year in unique_years])
plt.legend()
plt.tight_layout()
plt.show()

The Logit Normal model has smaller error bars. This may be because it is a better match for unbounded, potentially skewed data and therefore the posterior uncertainty is less. The model is locking in on a shape that the data strongly supports.

It is also estimating higher score means for all years. Perhaps it is also due to how it captures the left skewness of the data. Ultimately, we need to compare the posterior predictives.

The Logit‑Normal model appears to provide a better fit to the data than the previous no-pooling and hierarchical Normal models. Although it still slightly underestimates counts in the highest score bins and the mode bins are somewhat off, overall the posterior predictive plots align more closely with the observed data. Importantly, this improved model reinforces the evidence that 2021, 2022, and 2024 differ from 2023—with the 2023 scores showing a notably higher average performance.
