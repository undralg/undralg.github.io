Wrigley: the price of leverage

Does a $3 billion debt-funded payout create value once financial distress enters the picture?

Historical course case study

Capital structureAPVWACCSensitivity analysis
Read analysisOpen financial model

The approach

Compared tax-shield value, post-recapitalization borrowing costs, interest coverage and expected distress costs. Examined dividends versus repurchases and the difference between EPS mechanics and shareholder value.

What the analysis shows

The report’s no-distress tax shield is $1.2 billion. Its B-rated base scenario reduces net value creation to $732 million; a higher conditional distress loss reduces it to $576 million. The recommendation is sensitive to the debt capacity and distress assumptions.

How to read the results

The linked report is labeled a working draft. Values are case-model estimates, not realized outcomes; the distress scenarios depend on assumed conditional losses.
